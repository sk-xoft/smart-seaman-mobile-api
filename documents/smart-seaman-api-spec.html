Smart Seaman Mobile API

REST API for maritime training and certification management.
Spring Boot 2.6 · Java 11 · JWT Auth · Stateless

Base Information

Base URLhttp://localhost:8080
API Version/v1 prefix on all versioned endpoints
Content-Typeapplication/json
Swagger UI/smart-seaman-swagger
Timezone

Asia/Bangkok (UTC+7)

Authentication

Type

Bearer JWT Token

HeaderAuthorization: Bearer <token>

1. Call POST /v1/login with your credentials.
2. Copy the token value from the response data object.
3. Include it as Authorization: Bearer <token> on every protected request.
4. When the access token expires, use GET /v1/refresh-token?refToken=<refToken> to get a new one.

Response Envelope

All successful responses are wrapped in:

"code": "SUCCESS",
"description": "...",
"data": { ... }
